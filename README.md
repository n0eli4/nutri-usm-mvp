# Nutri Smart

Crea una aplicación web de registro de alimentación para estudiantes universitarios llamada NUTRIUSM. Debe ser un prototipo mobile-first, rápido y limpio, con colores verdes/frescos y navegación simple a Buscar/Registrar, Diario y Progreso. Implementa: buscador de alimentos por nombre con detalle de porción, calorías, proteínas, carbohidratos y grasas; flujo para añadir varios alimentos y cantidades a una comida; Diario del día con desayuno, almuerzo, once y cena, confirmación visual al registrar; dashboard de metas diarias versus consumo mediante barras/porcentajes. Precarga alimentos comunes, diario de un par de días y metas de ejemplo. No incluyas login, autenticación ni comunidad.
